# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Littlewood (https://littlewood.io; the site is branded only “Littlewood” since 2026-10-29, the old name 小木块 is gone from pages, OG images and logo.svg) — a static Chinese science site: “impossible”-looking science questions, answered with a few figures (tagline “直觉之外，另有秩序”). Three full-screen three.js 示意 pages: `/riemann-hypothesis`, and since 2026-10-30 `/space-acrophobia` ("在太空失重，还会恐高吗？", EVA height vertigo / visual reorientation) and `/hydrostatic-paradox` ("为什么 1 千克的薄层水，仍可能让挡板承受 1000 吨力？", hydrostatic pressure paradox) — the latter two were figure articles before; the 3D versions replaced them. three.js r128 is self-hosted under `public/vendor/`.

- Plain static files in `public/`, no build step. Self-hosted libraries are fine (put them under `public/`, load only on the page that needs them, keep the CSP in `_headers` at `self`; the only outside hosts are Cloudflare Web Analytics, which Cloudflare injects: `static.cloudflareinsights.com` in script-src, `cloudflareinsights.com` in connect-src). Shared code lives in a few files (2026-09-07, replaced the old "every page self-contained" rule):
  - `site.css` — tokens, board background, fonts, focus, reduced-motion. Every page links it.
  - `article.css` + `article.js` — (since 2026-10-30 no live page is a figure article any more: `article.css` is still used by the 404, `article.js` by nothing; both kept for a future figure article) everything the 图解 pages share (topbar, hero/conflict block, figbox, formula, key, demo controls, compact-details, footer, scroll reveal). Layout (2026-10-30): `main` is 848px wide, but text-level blocks that are direct children of a `section` (p, h3, ul, .formula, .key, .quote, .warn, .matnote, .compact-details) are capped at 720px (~45 汉字 a line) while figures, demo cards and `.panels` use the full width; h2 has no underline, sections are separated by spacing alone. Articles link both (`article.css?v=5`, `article.js?v=2`); page-specific colors and demo logic stay in the page's own `<style>`/`<script>`. Simplified 2026-10-29: no quicknav, reading progress, back-to-top, mascot bubble, article meta, layer-break or 误解排雷 section any more — don't add them back.
  - `scene.css` + `scene.js` — everything the three.js pages share (rebuilt 2026-10-30 after the overlay version read as cluttered). Layout is a three-row CSS grid on `body`, the same at every size (the user rejected a left/right split): `.topbar` (brand + series, 848px column), `.stage` fixed at 56svh (44svh on phones), `.panel` scrolling below it with its content centred in the same 848px column. Nothing floats over the scene. `.panel` is a solid, scrollable column in reading order: `h1` (the question, gold) → one or two `p` (the setup; `.answer` bold) → `.controls` (a `.row` of two pill buttons, then optional `.ctl` rows: label + range + output) → `.readout` (a tinted box: `.nums` line of coloured figures + `.insight` sentence; `aria-live`) → `details` 为什么 → `.legend` (pushed to the bottom with `margin-top:auto`: how to interact, 概念示例 note, sources). Reading order everywhere: picture first, then explanation and controls (the user's call). `scene.js` exports `fitStage({camera, renderer, controls, radius | extent, canMove})`: appends the canvas to `.stage`, sizes the renderer to it (ResizeObserver), and backs the camera off along its current direction until a sphere of `radius` fits the stage; `canMove` false means resize only (used while in first person). Page-specific colours (button accents, readout figure colours, in-scene `.tag` labels on the hydrostatic page, which live inside `.stage` at `z-index:2`) stay in the page `<style>`. Both files are versioned by query (`scene.css?v=4`, `scene.js?v=2`); bump on change.
  - `mark.svg` — the logo mark as `<symbol id="mark">`; pages draw it with `<svg viewBox="10 12 82 74"><use href="./mark.svg#mark"/></svg>` (404 uses the absolute `/mark.svg` because it serves at any path; since 2026-10-30 the 404 also links `/article.css` and is laid out as “an article that isn't there”: the article topbar with `404` in the series slot, gold h1, one line, one gold CTA back home — no card, no face, no link to a specific article). Figures/SVG stay inline in the page.
  - Shared files are cached 7 days via `_headers`; bump the `?v=N` on the `<link>`/`<script>` tags in all pages when a shared file changes.

Arrows are cylinder+cone meshes (`fatArrow`): blue pressure arrows on the old board (length ∝ depth, hidden for the solid), orange F原 pushing the old board from outside, purple F新 pushing the new board from the uphill side (so the thin layer reads as squeezed between two near-equal forces), green weight component inside the layer. `换成固体` swaps materials and the numbers (F原 = w, no F新). - `public/space-acrophobia.html` — three.js scene page (2026-10-30): a space station module with truss and solar wings, a gold handrail at the world origin, a blocky astronaut whose hands hold the rail, a procedural Earth (`ShaderMaterial` with fbm noise for continents/terrain/clouds and blue haze at grazing angles; R=420 at distance 470 so it subtends the ~140° it really does from 400 km; the sphere's pole is rotated sideways so nadir is equatorial), a star field. No OrbitControls in first person; `prefers-reduced-motion` makes the blends instant. Third-person framing is `fitStage` with `canMove` false while in / blending to first person.

## Conventions

- Keep kg (mass) vs kgf (force) strictly separated in copy — the hydrostatic article's whole point is not confusing them.
- Force-arrow colors are semantic and consistent across every figure: orange F原 `#ff7a2f`, purple F新 `#9775fa`, green gravity `#3fcf6a`, teal normal force `#22c3dd`, blue pressure distribution `#4dabf7`. Don't reassign them.
- Article 02 (perception) uses its own set: green real gravity (same meaning), teal vestibular signal, blue visual cue, red "大脑认定的下", orange fear/alarm. Astronaut is the `#astro` / `#astro-stand` `<symbol>`-style groups in the page's hidden defs SVG.
- Dark theme (2026-10-29, replaced the chalkboard): page ground is deep navy-black `#050510` with two faint radial glows (mint top-left, lavender bottom-right); panels are glass — `rgba(8,8,20,.75)` + `blur(8px)` + 1px `rgba(120,140,255,.25)` border (`.glass` in `site.css`; `article.css` applies it to `.card/.figbox/...`). Text is lavender white `#e0e0ff` (muted `#b8c0e0`, dim `#8899cc`), headings `#aaccff`, accents gold `#ffd966` (titles, CTA, numbers) and mint `#66ffcc` (links, series tag, answers). Token names in `site.css` kept their old chalkboard names (`--chalk`, `--yellow`, `--board`) so pages didn't change. SVG figures are drawn on the dark panel too (`.figbox svg` / `.item svg.thumb` background `--panel-solid` `#0d0d24`): paper `#0d0d24`, ink text `#e0e0ff`, greys `#a3acbd`/`#9aa4b8`/`#8f9bb3`, light objects (astronaut, boards, cards) stay light, and the semantic colors are the brightened set — green `#3fcf6a`, teal `#22c3dd`, blue `#4dabf7`, red `#ff6b6b`, orange `#ff7a2f`, purple `#9775fa`, water `#4aa3ff` / `rgba(74,163,255,x)`. Use these in new figures and legend swatches. No tape corners, no dashed rules, no rotation — clean panels like the Riemann page.
- Logo (2026-10-29): a dark rounded tile (`#0d0d24`, lavender border) with a gold slope and the small wood block (#d9a05e/#a86f32). Same mark in favicon.svg, icon-*.png, logo.svg, index cover, 404 (tile with a chalk-grey face) and OG images; bump `favicon.svg?v=N` + `.png?v=N` when it changes. The wood-block mascot bubble was removed from the articles on 2026-10-29. OG PNGs are rendered from HTML with the headless shell (1200×630): dark bg, glass panel, mint eyebrow, gold headline, lavender subtitle.
- Copy no longer says “用中学知识” (dropped 2026-10-29): the site tagline is “直觉之外，另有秩序” (2026-10-29; the word 反直觉 was dropped from all copy too); don't reintroduce the middle-school framing or 反直觉 in titles, meta or OG images.
- Numbers on the page are labeled "概念示例" (conceptual examples); don't present them as measured values.

## Editorial principles (site review, 2026-09)

- Question site, not knowledge site: every article opens with an "impossible" question and answers it; knowledge is the tool, never the topic. Titles are questions, not textbook entries.
- One layer only (2026-10-29): hero question + 猜猜/答案, 2–3 sections with the figures that carry the logic, the interactive demo, then 最后只记住这两行. The deeper explanations, misconception lists and most `<details>` were cut; keep new articles at this length (~5 figures).
- Figures carry the story: figures + captions alone should convey ~70% of an article; one figure answers exactly one question; formulas support figures, not prose.
- Interactives stay deliberately simple: 1–2 variables, purpose is understanding, not simulation.
- No visible numbering (2026-10-29): no section numbers on h2, no “图解 NN” tags on the home cards, article topbars or OG images. Keep the English-slug URLs (e.g. /hydrostatic-paradox); every page carries `<link rel=canonical>` + OG tags.
